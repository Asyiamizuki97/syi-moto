# SYI MOTO — Motorcycle Ad Prototype

A browser-based 8-second vertical motorcycle advertisement prototype.

## Setup

The project will use `assets/reference.jpg` for the supplied face reference. Add the reference image at that path once it has been uploaded to the repository.

Open `index.html` locally or enable GitHub Pages to preview the prototype.

> This is a code-based animation prototype, not generated live-action footage. The supplied face image is displayed as an image asset; code alone cannot generate a photorealistic moving face or synthesize realistic hair.
